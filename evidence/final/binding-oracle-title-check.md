## 판정 — **H1 확정** (키오스크 제출 문서에는 붙지 않는다)

"[바인딩 오라클]" 접두어가 붙은 문서는 **2건뿐**이고, 둘 다 **운영 템플릿이 아닌
구본 템플릿 `0c05c0146e794db385ff1cd32c9bcf30` "방문자 기록부(방명록) v1 구본(날짜기본값 없음)"**
에 `tools/binding-probe.mjs` 가 만든 API 검증 문서다. 키오스크(래퍼)로 제출된 문서는
**한 건도 이 접두어를 갖지 않는다.**

사용자가 본 화면은 콘솔 「완료 문서」함으로 추정된다. 이 목록은 템플릿을 가리지 않고 섞어
보여 주므로, 같은 시간대에 만들어진 구본 템플릿의 검증 문서 2건이 방명록 기록 사이에 끼어
보인 것이다.

H2(템플릿 설정에 문자열 잠복) · H3(배포본이 문서명을 보냄) 은 아래 증거로 **모두 부정**된다.

1. `tools/list-docs.mjs` — title 컬럼 버그 수정(`d.title` → `d.document_name`).

## 남는 사실 (지식화)

- **API `document.document_name` 은 템플릿 `doc_default_title` 규칙보다 우선한다.**
  API 로 만든 문서만 제목 규칙에서 벗어나므로, 완료 문서함에서 규칙과 다른 제목이 보이면
  브라우저 제출이 아니라 API 생성 문서를 의심하라.
- 외부 작성자(`recipient_type:"02"`) 문서는 `documents.list` 에서 `type:"04"` 로만 조회된다.
  `type:"01"`·`type:"02"` 는 0건을 돌려주므로 "문서가 없다"고 오판하기 쉽다.
- `documents.list` 의 `pageSize` 는 20 을 넘겨도 20 건까지만 돌아온다.
